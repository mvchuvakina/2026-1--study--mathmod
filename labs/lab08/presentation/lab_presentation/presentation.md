# 1. Цель работы

Изучить математическую модель конкуренции двух фирм,
производящих взаимозаменяемые товары, построить графики динамики
оборотных средств для различных режимов конкурентной борьбы.

# 2. Задание

1. Создать рабочий каталог для кода.
2. Реализовать модель конкуренции двух фирм в Julia.
3. Построить графики для двух случаев:
   - только рыночные методы конкуренции;
   - с учётом социально-психологических факторов.

# 4. Математическая модель

Система дифференциальных уравнений:

$$
\frac{dM_1}{d\theta} = M_1 - \frac{b}{c_1} M_1 M_2 - \frac{a_1}{c_1} M_1^2
$$

$$
\frac{dM_2}{d\theta} = \frac{c_2}{c_1} M_2 - \frac{b}{c_1} M_1 M_2 - \frac{a_2}{c_1} M_2^2
$$

где:
- $M_1(t)$, $M_2(t)$ — оборотные средства фирм;
- $\theta = t/c_1$ — безразмерное время;
- $a_1, a_2, b, c_1, c_2$ — коэффициенты.

---

# 5. Расчёт коэффициентов

Формулы для коэффициентов:

$$
a_1 = \frac{p_{cr}}{\tau_1^2 \tilde{p}_1^2 N q}, \quad
a_2 = \frac{p_{cr}}{\tau_2^2 \tilde{p}_2^2 N q}, \quad
b = \frac{p_{cr}}{\tau_1^2 \tilde{p}_1^2 \tau_2^2 \tilde{p}_2^2 N q}
$$

$$
c_1 = \frac{p_{cr} - \tilde{p}_1}{\tau_1 \tilde{p}_1}, \quad
c_2 = \frac{p_{cr} - \tilde{p}_2}{\tau_2 \tilde{p}_2}
$$

**Результаты:**

| Коэффициент | Значение |
|-------------|----------|
| $a_1$ | $1.122 \times 10^{-5}$ |
| $a_2$ | $1.082 \times 10^{-5}$ |
| $b$ | $1.214 \times 10^{-10}$ |
| $c_1$ | $0.13333$ |
| $c_2$ | $0.12364$ |
| $c_2/c_1$ | $0.9273$ |

---

# 6. Случай 1: Только рыночные методы

**Характер роста:**
- Обе фирмы демонстрируют S-образный рост
- Фирма 2 (стартовые средства 9.5) имеет преимущество
- Плавный характер без резких колебаний
- Стационарное состояние достигается к $\theta \approx 30$



---

# 7. Случай 2: С учётом соц.-псих. факторов

Добавляется социально-психологический фактор ($\Delta = 0.00046$):

$$
\frac{dM_1}{d\theta} = M_1 - \left( \frac{b}{c_1} + \Delta \right) M_1 M_2 - \frac{a_1}{c_1} M_1^2
$$

**Характер роста:**
- Усиление конкурентной борьбы
- Более резкий перегиб кривых
- Стационарное состояние достигается быстрее ($\theta \approx 25$)



---

# 8. Сравнение случаев 1 и 2



**Анализ:**
- Сплошные линии — случай 1 (только рыночные методы)
- Пунктирные линии — случай 2 (с соц.-псих. факторами)
- Во втором случае наблюдается более резкий перегиб
- Социально-психологические факторы усиливают конкурентную борьбу

---

# 10. Стационарные точки

Стационарные точки находятся из системы:

$$
\begin{cases}
M_1 - \frac{b}{c_1} M_1 M_2 - \frac{a_1}{c_1} M_1^2 = 0 \\[10pt]
\frac{c_2}{c_1} M_2 - \frac{b}{c_1} M_1 M_2 - \frac{a_2}{c_1} M_2^2 = 0
\end{cases}
$$

Для параметров варианта №56 ненулевое решение ($M_1 > 0$, $M_2 > 0$)
существует, что соответствует устойчивому функционированию обеих фирм.

---

# 11. Поведение модели при различных соотношениях

| Соотношение | Поведение |
|-------------|-----------|
| $\Delta = 0$ | Чисто рыночная конкуренция |
| $\Delta > 0$ | Усиление конкурентной борьбы |
| $\Delta$ велико | Возможно вытеснение одной фирмы |

Коэффициенты влияют:
- $a_1$, $a_2$ — на самоограничение роста
- $b$ — на взаимное влияние фирм
- $\Delta$ — на социально-психологический фактор
